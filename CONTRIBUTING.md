# Contributing to Mudi Dokan Khata

We welcome contributions! If you'd like to help improve the project, please follow these steps:

## Setting up your environment

1. Fork the repository.
2. Clone your fork locally.
3. Follow the instructions in [README.md](README.md) to start the backend API and frontend application.

## Making Changes

1. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Make your changes in the codebase.
3. Test your changes locally to ensure everything works as expected.

## Submitting a Pull Request

1. Commit your changes with a clear and descriptive commit message.
2. Push your branch to your fork.
3. Open a Pull Request against the main repository.

> [!NOTE]
> Please ensure your code follows the existing style and architecture of the project.
